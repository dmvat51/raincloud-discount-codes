## 这几个坑，踩过的人不少

**把"首月5折"理解成"长期5折"**。这是搜索这个词的人最容易产生的误解。首月5折只在第一个计费周期生效。

**用续费券去比新购券的价格**。新购券折扣明显更低，续费券一般到85折为止，别拿两者互相参照。

**忽略了区域差异**。部分区域不参加年付7折，结算页会很诚实地告诉你——如果总价没变，说明折扣没生效。

**以为活动券可以留着慢慢用**。节日券有时效也有库存，21:00 之后去看当天的券大概率已经空了。

**领了产品积分再想退订**。官方文档里写得很明白：领取产品积分后通常无法退订，这个顺序别搞反。雨云支持7天无理由退款，每账号限3次，但和有积分领取的产品规则会打架。

**没注意流量型套餐的限速**。限流量方案里用不完的流量可以逐月叠加、次月不清零，但流量用完后会限速（不同区域限速值不同，有5Mbps也有1Mbps的），恢复高速要额外买流量包，比如 200GB 约50元、1TB 约200元。选套餐时把流量上限算进去，比研究折扣码更影响实际体验。
